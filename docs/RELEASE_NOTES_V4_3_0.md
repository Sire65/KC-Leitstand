# Release Notes V4.3.0 Candidate

## Neu
- Fachlich getrennte Dashboard-Register: Internet, FRITZ!Box, WLAN, PC, Drucker, Multimedia, NAS, weitere Geraete und Protokoll.
- Internet zeigt nur Internetwerte; PC zeigt nur PC-/Windows-Werte.
- Zentrale SensorRegistry mit eindeutiger Sensor-ID und genau einem primaeren Register.
- Leere kuenftige Fachregister starten keine Messungen und erzeugen keine Doppeltests.
