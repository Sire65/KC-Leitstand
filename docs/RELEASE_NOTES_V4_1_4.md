# Release Notes V4.1.4

Status: REGISTER_COCKPITS_ASSISTANT_FIX_CANDIDATE

Diese Version korrigiert die Register- und Bedienlogik der V4.1.3. Jede Registerkarte zeigt jetzt eigene Inhalte statt dieselben globalen Instrumente darunter. Die Startseite erhaelt Hauptschalter, Router-Erkennung und gefuehrten Assistenten als direkte Bedienpunkte.

## Schwerpunkte

- Eigene Register-Cockpits fuer Internet, Router, Import, WLAN, PC/SMART und Protokoll.
- Keine doppelten Schalter auf Instrumentkarten.
- Hauptschalter direkt auf der Startseite.
- Router erkennen direkt erreichbar.
- Infofenster in Einstellungen abschaltbar.
- Sanduhr, Scanring und Herzform wieder beweglich und sauber geformt.
- Gefuehrter Assistent mit Schritt-fuer-Schritt-Pruefung.

## Nicht geaendert

- Keine neuen Framework-Cores.
- Keine Aenderung am lokalen PowerShell-Pruefdienst.
- Keine Aenderung an NavigationCore, WindowCore oder TableCore.
