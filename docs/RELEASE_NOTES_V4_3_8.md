# Release Notes V4.3.8 Candidate

V4.3.8 ist eine gezielte P1-Reparatur der Framework- und TÜV-Integrität. Die Leitstand-Fachfunktionen und das bestehende Bedienbild wurden nicht grundlegend umgebaut.

## Änderungen
- reale Runtime-Aktivierung aller registrierten allgemeinen Framework-Cores
- Consumer-Nachweis je Core
- NavigationCore an vorhandenen Leitstand-Adapter angebunden
- Versionskonsistenz auf 4.3.8 hergestellt
- Zertifikatsbildung von Python-Cachedateien bereinigt
- semantischer App/Public-Abgleich
- verschärfter Core-Runtime-TÜV
- neues V4.3.8-SHA-256-Manifest

## Status
Candidate, ausschließlich Testbetrieb. Keine GitHub-Veröffentlichung ohne ausdrückliche Freigabe.
