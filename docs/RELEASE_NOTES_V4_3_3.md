# Netzwerk-Leitstand V4.3.3 Candidate

## FRITZ!Box-Paketmitschnitt
- Import klassischer `.eth`- und `.pcap`-Dateien direkt im Browser.
- Lokale Metadatenanalyse ohne Upload.
- Protokolle, Dienste, Endpunkte, Verbindungen, DNS-Anfragen, TCP-Resets und moegliche Wiederholungen.
- Datenverlaufsdiagramm und JSON-Export.
- Bestehende Mess- und Probe-Logik unveraendert.

## Grenzen
- PCAP-NG wird noch nicht gelesen; in Wireshark als klassisches PCAP speichern.
- Keine Nutzdaten-/Kennwortanzeige.
