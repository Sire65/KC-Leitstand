# AUDIT V5.4.0 – BrainCore V2 Organism Runtime

## Scope
Controlled correction of the BrainCore runtime only: authoritative state mapping, continuous load model, organic breathing, asynchronous strobes, visible neural pulses, lightning activity and compact/prominent placement.

## Fixes
- Coordinator is the single source of truth for brain colour and alarm state.
- Unknown/inactive sensors no longer force yellow.
- Red/critical organism states immediately reach the BrainCore.
- Brain load changes continuously and retargets without jumps.
- Strobe scheduling initialization fixed; each edge runs independently.
- Neural pulses and occasional lightning are visible at all states, scaled by load.
- Router card compacted; complete cube receives more space and higher stacking level.
- Static fallback remains available when TransitionService is absent.

## Boundaries
No changes to navigation, tables, measurement acquisition or external device actions.
